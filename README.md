# 學字樂園

俾 5 歲小朋友學繁體中文字嘅 iPad web app。用廣東話電腦把聲讀字，暫時唔教拼音。

## 功能
- **開始學字**：每堂 3 個新字，加埋到期要溫嘅舊字（最多 6 個）。先介紹新字，之後玩揀字遊戲：聽讀音，喺 3 個字入面揀啱嗰個。
- **間隔重溫**：答啱就隔耐啲先再溫（1、2、4、7、14 日），答錯就盡快再溫。
- **貼紙簿**：每上完一堂得一張貼紙。
- **我識嘅字**：睇返學過嘅字，撳個字會讀出嚟。
- **家長設定**：長按右下角 ⚙️ 1.5 秒先入到，可以睇進度、試把聲同清除進度。

進度儲存喺 iPad 瀏覽器入面（localStorage），唔使帳戶。

## 喺 Mac 度開
```bash
python3 -m http.server 8765 --bind 0.0.0.0
```
之後打開 http://localhost:8765

## 放上 iPad
**方法一：同一個 Wi-Fi（最快）**
1. 喺 Mac 跑上面個指令
2. 喺 iPad Safari 打開 `http://<Mac 嘅 IP>:8765`（Mac IP 可以喺「系統設定 → Wi-Fi → 詳細資料」搵到）
3. 撳分享 → 「加至主畫面」

呢個方法要 Mac 開住先用到，亦唔可以離線用。

**方法二：放上網（GitHub Pages / Netlify 等）**
用 https 開，加到主畫面之後冇網都用到。

## iPad 廣東話把聲
如果家長設定顯示「搵唔到廣東話聲」：
設定 → 輔助使用 → 朗讀內容 → 聲音 → 中文（香港），下載一把聲（建議揀「增強版」，自然啲）。

## 字庫
分 11 關（身體同大自然、數字、屋企人、動物、顏色、天氣、方向、食嘢、做嘢、返學、形容），共 122 個字、79 個詞語。每關先學單字，再學用學過嘅字組成嘅詞語（例如學咗「火」同「山」先會學「火山」）。過咗一關會有特別恭喜。

## 加字
喺 `index.html` 嘅 `LEVELS` 揀一關，喺 `chars` 加一行：
```js
{ c: '字', e: '🔤', say: '字，寫字嘅字' },
```
`say` 係電腦讀嘅句子，用「X，YY 嘅 X」幫小朋友分辨同音字。

加詞語就喺 `words` 加（`say` 可以唔寫，會直接讀個詞）：
```js
{ c: '火山', e: '🌋' },
```
詞語入面每個字都要喺同一關或者之前嘅關出現過。新增嘅字最好加喺後面，咁已經學緊嘅小朋友進度唔會亂。
